# Agent Office

AI 에이전트와 사람이 회사처럼 역할을 나누고, 사용자가 만든 업무 프로세스에 따라 협업하는 데스크톱 앱입니다. Windows, macOS, Linux를 대상으로 **Go + Wails**로 만듭니다.

M6(출시 검증)까지 마쳤고, 그 위에 서비스 운영(사건과 자료로 협업하는 작은 회사) 기능을 더했습니다. 진행 상태는 [진행 상황](docs/progress.md)과 [서비스 운영 진행 기록](docs/plan/service-operations/progress.md)에, 시험 증거는 [인수 테스트 증거](docs/acceptance.md)에 있습니다.

## 주요 기능

- 사용자가 조직과 역할, 역할별 지침, 업무 흐름을 직접 구성합니다.
- AI가 요청에 맞는 역할과 업무 흐름을 제안하고 담당자를 배정합니다.
- AI 에이전트와 사람이 같은 업무 흐름에서 작업과 검토를 나눠 맡습니다.
- 게임 개발, 부동산 분석 등 서비스를 프로젝트별로 분리해 관리합니다.
- 서비스를 작은 회사로 보고, 부서가 업무·자료 사건과 정기 점검을 보고 업무를 제안하거나 서로 협업을 요청합니다. 업무마다 어떤 사건 때문에 시작했는지 따라갈 수 있습니다.
- 기획 승인, 반려, 병렬 작업, 재작업, 실행 중단과 재개를 처리합니다.
- 귀여운 도트 오피스에서 담당자와 업무 진행 상황을 시각화합니다.
- Codex와 Claude의 CLI·API 연결을 단계적으로 지원합니다.

## 개발 방향

Go가 업무 실행과 저장, 외부 도구 연결을 담당하고, Wails와 React·TypeScript가 데스크톱 UI를 구성합니다. 업무 편집기는 노드 기반으로 제공하며, 도트 오피스는 실제 실행 이벤트를 화면에 반영합니다.

구현은 상세 계획서의 M0~M6 단계에 따라 진행합니다. 기술 검증과 최소 업무 실행부터 시작해 실제 AI 연결, 자동 구성, 협업, 시각화, 운영체제별 검증으로 확장합니다. 개발 중 확정한 결정과 진행 상태는 파일로 기록해 다음 세션에서도 이어갈 수 있도록 합니다.
